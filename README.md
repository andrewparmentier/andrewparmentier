# Andrew Parmentier

Strategy and business development executive in Boulder, Colorado. Two-time founder: Height Capital Markets (sold 2017) and Ducks Rising (sold 2026).

I build my own tools with AI. Since early 2026 I've written about 50,000 lines of code with Claude Code, most of it automating investment research I used to do by hand. I write the spec, an agent writes most of the code, and I review, test and ship.

## What I've built

- **AI research stack**: an ingestion pipeline that turns filings, transcripts, articles, books and video into structured research notes, plus the risk controls I run on top of it. Write-up coming soon.
- **[Second-Brain](https://github.com/andrewparmentier/Second-Brain)**: the Obsidian and Claude API knowledge system underneath it. Drop a file or clip a page, get a linked research note.
- **CapCommit**: side project. A college-recruiting tracker for youth water polo families, built solo on Supabase and Vercel. Beta November 2026.

## Stack

Python, TypeScript, Supabase, Vercel, Claude API, Claude Code, Obsidian, macOS launchd.
